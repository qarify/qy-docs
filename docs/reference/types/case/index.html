TestCase Schema

Represents a single, atomic test case that verifies a specific piece of functionality. A test case consists of a sequence of steps (actions and expectations).

This type is translated into a JSON schema for validation and documentation purposes.

Properties

NameTypeDescriptionRequired
idstringA unique identifier for the test case. It is recommended to use a UUID.
Format: "uuid"
yes
titlestringA human-readable title for the test case.
yes
namestringAn optional, machine-readable name for the test case, used as a slug.
Should contain only lowercase letters, numbers, hyphens, and underscores.
Pattern: ^[a-z0-9-_]+$
no
descriptionstringA detailed description of what this test case is testing.
no
beforearrayAn optional array of setup steps to be executed before the main test steps.
no
testsarrayThe sequence of steps that constitute the core logic of the test case.
yes
afterarrayAn optional array of teardown steps to be executed after the main test steps,
no
dataobjectno
selectorsobjectno
skipbooleanIf true, this test case will be skipped during execution.
Default: false
no
timeoutintegerThe maximum time allowed for the test case to run, in milliseconds.
A value of 0 means no timeout. This overrides any timeout set at the suite level.
Minimum: 0
no
parentIdstringThe unique identifier of the parent test suite.
Format: "uuid"
yes
metaobjectAn object containing metadata for the test case.
no

Example

{
  "before": [
    {
      "runIf": {}
    }
  ],
  "tests": [

  ],
  "after": [
    {
      "runIf": {}
    }
  ],
  "data": {},
  "selectors": {},
  "skip": false,
  "meta": {}
}
