🚀 Quick Start

Qy Studio에 오신 것을 환영합니다! 본 가이드는 프로젝트 생성부터 AI 기반 테스트 케이스 작성 및 실행까지의 기본 흐름을 빠르게 익힐 수 있도록 도와드립니다.

📜 1. 사전 준비​

시작하기 전, 환경에 맞는 Qy Studio 설치를 완료해 주세요.

  • Qy Studio 설치 가이드

🎯 2. 신규 프로젝트 생성​

테스트 시나리오와 자산을 관리할 작업 공간을 만듭니다.

  1. Qy Studio를 실행합니다.
  2. 메인 화면의 [New Project] 버튼을 클릭합니다.
  3. 프로젝트 기본 정보를 입력합니다.
  • Project Name: 프로젝트 구분 이름
  • Directory: 프로젝트 파일이 저장될 로컬 경로
  1. [Create] 버튼을 클릭하여 프로젝트 생성을 완료합니다.

⚙️ 3. AI 프로바이더 설정​

자연어 기반 테스트 개선 및 자동 생성을 위해 사용하실 LLM(AI 모델)을 연동합니다.

  1. 상단 글로벌 헤더 오른쪽의 [Settings] (톱니바퀴 아이콘)를 클릭합니다.
  2. AI Providers 항목을 펼친 후 [Add Provider]를 클릭합니다.
  3. 서비스에 사용할 AI 정보를 입력합니다.
  • Base URL: 사용 중인 AI 서비스 엔드포인트
  • API Key: 발급받은 API 키
  • Models: 연동할 AI 모델 명칭
  1. [Save Provider]를 클릭하여 프로바이더를 추가합니다.
  2. 페이지 하단의 [Save Changes]를 눌러 최종 변경 사항을 저장합니다.

🔴 4. 테스트 시나리오 레코딩​

실제 웹 브라우저에서의 조작 과정을 녹화하여 테스트 기반 시나리오로 변환합니다.

  1. 상단 메뉴바의 [Record] 버튼을 클릭합니다.
  2. 팝업 창에 테스트할 웹사이트 URL을 입력한 뒤 [Start Recording]을 클릭합니다.
  3. 자동으로 열린 브라우저 창에서 [Start Recording]을 눌러 녹화를 시작합니다.
  4. 브라우저에서 레코딩하고자 하는 사용자 시나리오(클릭, 텍스트 입력 등)를 순서대로 수행합니다.
  5. 시나리오 수행이 끝나면 브라우저 상단의 [Finish] 버튼을 클릭합니다.
  6. 스튜디오로 돌아와 [Play] 버튼을 눌러 레코딩이 정상적으로 작동하는지 확인합니다.
  7. 확인이 완료되면 [Back]을 눌러 메인 목록으로 이동합니다.
  8. 생성된 레코딩 항목 우측의 [ More (...) ] 아이콘을 클릭한 후 [Add to Project]를 선택하여 프로젝트 자산으로 등록합니다.

🪄 5. 테스트 스위트 변환 및 AI 최적화​

탐색적으로 레코딩한 시나리오를 정형화된 Test Suite로 변환하고, AI를 통해 유지보수가 용이한 고품질 테스트 케이스로 최적화합니다.

  1. 레코딩 등록 후 화면 하단에 나타나는 토스트 알림에서 [Convert to suite]를 클릭합니다.
  2. 좌측 Explorer (Tree View)에 새롭게 생성된 Test Suite를 펼치고, 최적화할 Test Case를 선택합니다.
  3. 중앙 상세 패널(Detail Panel) 상단의 [Improve Test] 버튼을 클릭합니다.
  4. AI 분석 및 최적화가 완료되면 적용 방식을 선택합니다.
  • [Replace]: 기존 레코딩 스크립트를 AI 최적화 버전으로 교체 (권장)
  • [Append]: 기존 스크립트 하단에 최적화 코드 추가
  1. 최적화 완료 후, 가독성과 안정성이 향상된 테스트 스크립트를 확인합니다.

⚡ 6. 테스트 실행 및 결과 확인​

작성된 테스트를 실행하여 기능 동작 여부와 검증 결과를 확인합니다.

  1. 좌측 Explorer (Tree View)에서 실행할 Test Suite를 선택합니다.
  2. 중앙 상세 패널(Detail Panel)의 [Run] 버튼을 클릭합니다.
  3. 우측 Results Sidebar에서 실시간 테스트 진행 상태 및 성공/실패 리포트를 확인합니다.
